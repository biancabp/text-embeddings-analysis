# Text Embeddings Analysis

Análise de representações vetoriais de textos utilizando embeddings
gerados por modelos BERT.

## Objetivo

Investigar a estrutura semântica de um conjunto de textos através
de representações vetoriais e técnicas de redução de dimensionalidade.

## Técnicas

- BERT embeddings
- PCA
- t-SNE
- UMAP
- K-Means
- Visualização de clusters

## Tecnologias

- Python
- NumPy
- Scikit-learn
- BERT
- Matplotlib
